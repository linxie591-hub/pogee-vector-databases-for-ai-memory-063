# Vector Databases for AI Memory - Notes From Building

Vector search is the obvious answer for AI memory - and only half the answer.

Embeddings let you find semantically similar moments, but similarity is not importance. A throwaway joke and a life event can sit at the same cosine distance.

The mature stack blends vector recall with recency, salience, and explicit user signals so that the memory layer reflects what actually matters.

Retrieval quality, not index size, is what users feel.
